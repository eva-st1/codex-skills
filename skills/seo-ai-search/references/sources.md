# Origins and source policy

## Inspiration

Inspired by Matt Shealy / SwayyEm, [21 SEO Skills Built for Claude](https://www.swayyem.com/guides/21-seo-skills-built-for-claude), accessed 2026-10-05. The article describes coordinated research, page quality, technical checks, authority analysis, AI visibility, and reporting.

These are original Codex instructions organized around user tasks, with selective references rather than a copy of the article's prompt bundle. They retain connected analysis and page-specific recommendations. Speculative engine simulations, fixed ranking/anchor formulas, and mandatory placement prescriptions are replaced with observed data, explicit uncertainty, and current primary guidance. No affiliation or endorsement is implied.
